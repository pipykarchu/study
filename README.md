# 知芽 Study Bloom

浅粉与淡紫的个人学习花园。先明确知识框架和学习边界，再把目标变成可验证的小作品。

## 已实现

- 默认以“对话学习”进入：左侧对话与模拟测试，右侧显示目标、七步进度、真实分数和下一步。
- 保留学习花园、知识框架、今日学习、项目练习、学习方法、资料与备份。
- AI 产品成长、Vibe Coding、通用学习三套起步框架；目标、动机、作品和三份边界清单可编辑。
- 六个知识节点的动手任务、过关标准、笔记与自主验收。
- 10 次学习安排、任务清单、专注计时器、自动保存笔记与复盘。
- 带个人目标和边界的六种 Claude 提示词，一键复制。
- JSON 完整备份/确认导入与 Markdown 框架导出。
- 七步闭环：框架与边界 → 抓核心 → 分段练习 → 主动回忆测验 → 项目应用 → 费曼复述 → 速查复习。
- 三套参考题库共 36 道题；逐题提交、判分、解析、错题复测与复习安排。完整六节点普通测验达到 80% 才完成测验阶段；短测和错题复测不会冒充完整通过。
- 阶段完成须留下自己的学习证据，AI 回复和消息条数不会自动算作“学会”。

无构建步骤、无运行依赖。`dist/` 是完整静态站。用任意静态服务器打开，例如：

```sh
python -m http.server 4173 --directory dist
```

- [bili-learn](https://github.com/pipykarchu/bili-learn) 与 [pikarchu](https://github.com/pipykarchu/pikarchu)：作为已有公开项目的实践入口。
- 职业规划中“目标 → 章节 → 练习 → 项目 → 复盘”的流程用于产品结构；未拷贝私人档案或求职资料。默认方向是可切换的起步建议。

## 数据与能力边界

学习目标和笔记保存在当前浏览器的 localStorage（`study-bloom-v1`）；七步证据、模拟测试和错题保存在 `study-bloom-learning-v2`，完整 JSON 备份同时包含两者，可导出后换设备导入。兼容旧版备份，旧版未包含的测验记录会保留。知识掌握仍须结合实践验收，题库成绩不代表能力认证。不要在公开源码中提交个人学习备份、密钥或私人材料。

云端 Sites 默认仅站点所有者可访问。代码仓库可单独设置公开或私有；仓库中不包含个人学习记录。云端版与本机版是不同网址，浏览器记录不自动共享，可通过 JSON 备份迁移。

## 用自己的 Codex 直接问答

电脑已安装并登录 Codex 时，在本机运行：

```sh
node local/server.mjs
```

已完成本人绑定的 Windows 电脑可以双击根目录的 `启动知芽.cmd`，然后打开 [本机学习版](http://127.0.0.1:4175/#coach)。电脑和本机服务需要保持开启。

“对话学习”页使用本机已有登录，不需要把订阅凭据或 API Key 填进网页。优先使用本机配置的模型；如果当前账号的可用列表不包含该模型，仅给本学习会话选择该账号可用的默认模型，不修改全局配置。提问可选择携带学习目标与边界；支持流式回答、停止回答和新对话。对话暂留在当前网页标签页，不会自动继承桌面应用中已有聊天。学习笔记和聊天是不同记录，完整学习备份不包含聊天内容。

本机服务只监听 `127.0.0.1`，限定同源请求，校验请求令牌并限制单任务；通过 stdio 使用官方 Codex App Server。学习对话采用只读、禁止自动执行操作的权限配置。登录信息留在本机，未复制到云端。云端版提供本机入口，不会自动跨域连接你的电脑。

本机问答进一步校验已预先确认的所有者：只接受与 `.local-runtime/owner.json` 中邮箱 SHA256 一致的 ChatGPT 登录。该文件不进入源码或部署包；当前安装已绑定平台验证过的站点所有者，其他电脑需要由本人完成独立绑定，不能把首次任意登录自动当成所有者。每次提问重新核对身份，登录变化会停止正在回答的内容并作废会话；正常授权刷新也可能需要开新对话。

网站不收集、保存或转发 Codex 密码。云端访问使用 OpenAI 官方登录和 Sites 私有允许名单；本机服务拒绝跨站请求、错误 Host、缺少校验令牌的写请求、目录越界和超限请求。没有任何网站能保证绝对不被攻击；这些限制也不能防御已控制同一 Windows 用户或能修改本机文件的人。

Windows 上会优先保留显式代理环境；未设置时，本机连接器会把已启用的系统代理传给 Codex 子进程，并绕过本机地址。不会修改系统代理、全局 Codex 配置或父进程环境。

官方说明：[Codex App Server](https://learn.chatgpt.com/docs/app-server)。本地应用可使用本机登录；本项目没有把既有登录凭据转作云端托管服务凭据。
